      How it works

      • Americano: the whole schedule is made up front. Every round, partners and opponents change as much as they can, so nobody plays with the same person until they have to.
      • Mexicano: round 1 is mixed, then each round is built from the standings. The top four share court 1, the next four court 2, and so on. Inside a court 1st pairs with 4th and 2nd with 3rd, unless that repeats a partnership.
      • Sit-outs rotate: if there are more players than court places, the people with the fewest sit-outs so far are the ones who rest, so nobody sits twice before everyone has sat once.
      • Scores are the real points each side won, normally adding up to the points per match. Type one side and the other fills in as the remainder; change it if the match went differently.
      • Works for any social night where partners rotate: padel first, but also tennis, badminton and pickleball.

      Your data

      • The current night is saved in this browser's local storage, on this device only, so a refresh does not lose it. That is the only storage used.
      • No account, no cookies, no analytics. Nothing is sent anywhere. A snapshot link holds the standings inside the link itself, so anyone you send it to can read the names and scores in it.
      • The example uses invented first names and made-up scores.
